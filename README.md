# 维修报销 (Reimbursement)

一个专注「维修报销记账 + 报表统计」的轻量 Android 应用。只有支出（维修报销）一种账单类型，无收入概念。从 [捕账 (AppMessageCapture)](../AppMessageCapture) 精简而来。

## 功能

- **记账**：手动添加维修报销账单，六项信息：日期、驾驶员、车牌号（自绘车牌键盘：省简称面板自动切换字母/数字/学挂警港澳后缀，不调系统输入法）、内容、金额、图片（可拍照/相册多选，保存时随账单一并入库）；**全部字段均可留空**（金额留空按 0 记）；按天分组展示，账单行第二行显示驾驶员（左）与车牌号（右）（时间只到日，同一天内按添加顺序排列）；关键词搜索、多选删除、左滑删除、下拉统计面板、本月维修报销概览。
- **导出（顶栏图标）**：记账页顶部导航栏的导出按钮先选**按日时间段**（默认**最早账单日 ~ 今天**，开始晚于结束自动联动修正），生成**单个 xlsx**——仅一张「维修报销账单」表，列序 日期/驾驶员(宽20)/车牌号(宽20)/内容(宽40)/金额(宽20,¥货币)/图片（照片内嵌并**等比缩放、严格保持原图宽高比**——oneCellAnchor 绝对尺寸不被格子比例拉伸变形，数据行高 65 磅内垂直居中；图片列宽=一张照片的显示宽+4px（相邻照片留 4px 空隙）、金额列 ¥ 货币两位小数、表头浅灰底、表尾「总金额：」合计行红字黄底）后**直接弹出系统分享面板**，可直接发给微信好友/文件管理器；文件名含起止日期。
- **账单图片（多张）**：点击账单图标可拍照或从相册选图（相册一次最多选 9 张），一张账单可挂多张照片；**存储时统一压缩**（长边 1600px / JPEG 85，单张约 100~500KB；历史大图由启动迁移一次性压缩），图标显示第一张照片缩略图 + 张数角标；点击图标全屏翻页查看：双击/双指捏合缩放（放大后单指平移、不出视野），底部缩略图条点选跳转（当前张高亮并自动居中，微信/相册式交互），查看器内支持添加图片 / 删除本张。缩略图带内存缓存，删除账单/照片联动清理文件。
- **报表统计**：周报/月报/年报/自定义时间段（≤366 天），维修报销总额、日均/月均、环比对比、趋势折线图、近 6 周期柱状图。
- **系统分享接收**：截图编辑器 / 微信等任意应用分享图片时可选「维修报销」，进入选账单界面（最近 50 条 + 搜索），选中即把图片压缩挂到该账单；多图分享逐张入账。
- **设置**：20 种预设主题色 + HSV 自定义取色（备份入口已迁至记账页顶部）；操作日志按天写入应用私有目录 `files/logs/`（增删改账单、图片、导出、主题色、保留时间调整等均记录），默认保留 30 天（可在设置调整 7~365 天，启动时自动清理过期文件），支持一键打包 zip 分享。
- **轻量化**：静态柔光背景（无动画光斑、无实时背景模糊），常驻 GPU/CPU 占用接近于零。

## 不包含（相对捕账裁剪的功能）

收入记账、账单分类、商户记忆、周期账单、平台账户、预算管理、自动记账（通知捕获 / 屏幕无障碍捕获）、生日提醒、消息中心、功能开关系统。

## 技术

- Kotlin + Jetpack Compose（Material 3，液态玻璃视觉语言：玻璃卡片、静态柔光背景）
- Room 双表（`bills` + `bill_photos` 一对多，版本 4，schema 已导出至 `app/schemas/`；v3→v4 迁移把单图列搬进多图表）
- 无第三方业务依赖；xlsx 读写为内置的 `MiniXlsx`（OOXML 内联字符串 + drawing 图片层实现），备份导出即单个 xlsx 文件
- 账单列表统一按时间倒序条数分页（LIMIT），补记历史日期的账单在所有视图一致可见
- 拍照经 `ActivityResultContracts.TakePicture` 调起系统相机（无需 CAMERA 权限），相册走 `PickVisualMedia` 隐私照片选择器；图片文件管理见 `utils/BillPhotoStore.kt`
- AGP 8.6.1 / Kotlin 1.9.24 / compileSdk 35 / minSdk 26

## 构建

```bash
./gradlew :app:assembleDebug        # 产物 app/build/outputs/apk/debug/维修报销-v1.0.0.apk
./gradlew :app:testDebugUnitTest    # 单元测试（报表日均/xlsx/备份往返）
```

- 包名：`com.zhaojin.reimbursement`
- 数据库：`reimbursement_database`（与捕账相互独立）
